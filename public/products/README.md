# Product photos

Drop your product images in this folder. Each file must match the `image`
filename in `lib/products.ts` exactly. Square photos (1:1) look best in the grid.

Expected files:

- olive-oversized-tee.jpg
- washed-black-hoodie.jpg
- wide-leg-cargo.jpg
- cream-linen-shirt.jpg
- faded-denim-jacket.jpg
- ribbed-knit-polo.jpg
- pleated-trouser.jpg
- sand-crew-sweatshirt.jpg
- utility-overshirt.jpg

Any missing image shows a labelled placeholder tile, so the site still runs
without them. To add/rename/remove products, edit `lib/products.ts`.
